# ⚡ AG Mode v0.1.0 — Initial Official Release

Welcome to the first official release of **AG Mode** (AntiGravity Mode Manager) by **Muhammad Wasif**!

AG Mode provides real-time, non-destructive mode management, domain personas, specialized quality gates, and toolchain rules for your Google AntiGravity AI assistant.

---

### 📦 Standalone One-Click Installers

Download the standalone package for your operating system:

- **Windows:**
  - `ag-mode-v0.1.0-windows-setup.bat` (Double-click batch installer)
  - `ag-mode-v0.1.0-windows-setup.ps1` (PowerShell installer)
- **macOS:**
  - `ag-mode-v0.1.0-macos-setup.command` (Double-clickable Finder installer)
  - `ag-mode-v0.1.0-macos-setup.sh` (Shell script installer)
- **Linux:**
  - `ag-mode-v0.1.0-linux-setup.sh` (Self-extracting shell installer)
  - `ag-mode-v0.1.0-linux.tar.gz` (Portable distribution archive)

### ✨ Key Features

- **70+ Domain Modes**: Pre-built modes across Web Development, Artificial Intelligence, Machine Learning, Chemistry, Digital Logic Design, Cybersecurity, Systems Programming, Mathematics, and Academic Research.
- **Instant Hot Reload**: Mode changes take effect immediately in AntiGravity with zero IDE restarts needed.
- **Universal ASCII Terminal UI**: Interactive category browser, live search, and full keyboard navigation.
- **Dual-Scope Architecture**: Automatically updates Global rules (`~/.gemini/config/rules/`) and Workspace rules (`.agents/rules/`).
- **Non-Destructive Safety**: Automatic snapshot backups and 1-command rollback.
- **Mode Composition**: Combine multiple modes simultaneously (`ag-mode compose`).
